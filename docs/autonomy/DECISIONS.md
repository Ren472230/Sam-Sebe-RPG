# Журнал долгоживущих решений

Этот файл хранит только решения, которые влияют на будущие автономные циклы.

## Формат записи

### YYYY-MM-DD – краткое название решения

- Решение: конкретно что принято.
- Основание: подтверждённые факты и ограничения.
- Влияние: какие части проекта или правила затронуты.
- Доказательство: ссылка на SHA, запрос на слияние, проверку, спецификацию или другой фактический источник.
- Статус: `active`, `superseded` или `reversed`.

## Решения

Первичная установка пока не содержит долгоживущих проектных решений. Первый автономный цикл добавляет запись только при реальной необходимости.
