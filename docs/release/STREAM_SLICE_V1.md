# Stream Slice v1 – World-Ready Demo Runbook

## Статус

Stream Slice v1 – проверенный браузерный vertical slice одного причинно связанного вечера в стартовой деревне, поверх которого уже работают Living World, Living NPC, Social World и Living Conversation v2.

Текущий проверенный runtime-чемпион автономного world-ready цикла:

`4b5d0e69c7542d315b277a18a102f8ee7b88bd96`

Рабочая ветка:

`autotest/world-ready-2026-09-08`

Validation PR:

`#47 – CI validation: autonomous world-ready cycle`

`main` остаётся контрольной веткой. Слияние в `main` выполняется только после отдельного явного решения.

Stream mode меняет подачу для зрителя. MOVE / WAIT / TAKE / GIVE, квесты, физическое состояние мира и причинность проходят через существующий authoritative backend.

## Что входит в текущий демонстрационный кандидат

- браузерная игра на Phaser/Vite;
- Python/FastAPI + SQLite как authoritative игровой слой;
- Living World с автономными событиями и расписаниями NPC;
- Living NPC со свободным диалогом и долговременной памятью;
- Social World с причинной передачей знаний и provenance;
- Living Conversation v2 с различающимися голосами NPC, внутренним состоянием, отношением, callback-памятью, открытыми темами и grounded initiative;
- первый понятный пользовательский маршрут: найти таверну, поговорить с Ореном, взять задачу, собрать дрова и вернуться;
- responsive shell, проверенный на ширине 390 px без горизонтального overflow;
- production-first визуальная архитектура: полностью готовая production-сцена имеет приоритет, текущая partial-production сцена честно использует цельный prototype fallback;
- независимый fallback для player/Oren/firewood: production sprite → prototype sprite → scene greybox.

Текущий production manifest остаётся частичным. Поэтому фактическая пользовательская сцена пока использует цельный prototype-визуал там, где полный production-набор ещё отсутствует.

Node.js: 22 рекомендуется и используется в CI.

Из корня репозитория:

```powershell
python -m pip install -e ".[dev]"

```

OpenAI API key опционален. Без ключа игра использует детерминированный grounded fallback диалог. Ошибка или timeout live-провайдера также переводит разговор в локальный fallback вместо остановки игры.

## Чистый запуск

Для воспроизводимой демонстрации:

```powershell
powershell -ExecutionPolicy Bypass -File .\RUN_STREAM_SLICE.ps1 -Reset
```

Открыть:

`http://127.0.0.1:5173/?stream=1`

`-Reset` затрагивает только изолированную Stream Slice БД:

- `data/stream-slice.sqlite3`;
- `data/stream-slice.sqlite3-wal`;
- `data/stream-slice.sqlite3-shm`.

Основная БД и e2e-БД этим сбросом не затрагиваются.

## Повторный запуск без сброса

Для продолжения уже существующего состояния:


Launcher автоматически запускает `scripts/stream_preflight.py`. При нарушении обязательных инвариантов запуск завершается до демонстрации.

## Первый понятный маршрут для публичного показа

1. После загрузки игрок сразу видит цель найти таверну и поговорить с Ореном.
2. В таверне разговор с Ореном приводит к основному заданию.
3. Цель показывает прогресс `дрова X/5`.
4. После сбора пяти дров игрок получает указание вернуться к Орену.
5. Завершённая задача переводит фокус на исследование деревни и живого мира.
6. Через WAIT можно показать движение мира и автономные события NPC.
7. Через разговоры с Мирой, Каспаром, Ореном и Таленом можно показать различие знаний, памяти, отношения и текущего состояния персонажей.
8. Reload демонстрирует сохранение канонического и социального состояния.

## Причинные сюжетные события Stream Slice

В свежей БД ориентир следующий:

1. **Шаг 0** – вечер начинается, деревня работает в обычном ритме.
2. **Около шага 5** – у Миры заканчивается пригодная древесина, и она просит помощь.
3. Игрок может пообещать Мире принести древесину. Это знание сначала остаётся у Миры.
4. Каспар до реального контакта с Мирой не знает об обещании игрока.
5. **Около шага 9**, если игрок не перехватил ситуацию, Каспар самостоятельно находит древесину и приносит её Мире. После реального контакта он может узнать от неё об обещании игрока.
6. **Шаг 10** – в таверну приходит Тален с новостью о размытой восточной дороге и задержке торгового каравана.
7. Орен получает эту новость от Талена и просит принести хлеб для гостя.
8. Хлеб можно подобрать на площади и физически передать Орену через TAKE / GIVE.
9. После передачи Орен подтверждает помощь.
10. После reload социальное знание и состояние мира сохраняются.

Точные формулировки диалогов могут отличаться при live-провайдере. Факты, причинность и server-side эффекты остаются ограничены каноническими контрактами.

## Living Conversation v2 в демонстрации

Разговоры теперь строятся поверх следующих слоёв:

- индивидуальный voice profile каждого NPC;
- текущее deterministic inner state;
- relationship behavior;
- NPC-scoped authoritative knowledge;
- pair-scoped conversational memories;
- незавершённые conversation threads;
- grounded initiative;
- optional player character context, который сам по себе не превращается в знание NPC.

LLM отвечает за язык и узко валидируемые conversational metadata. Физическое состояние мира, инвентарь, факты и причинные эффекты остаются под контролем backend.

## Что должен видеть зритель

Использовать URL с `?stream=1`.

Stream presentation показывает:

- текущий шаг и фазу вечера;
- NPC рядом;
- короткие публичные события мира;
- пользовательские имена NPC, включая `Тален`;
- обычные игровые действия и свободный диалог;
- понятную текущую цель игрока.

Зрительский слой скрывает внутренние actor id, raw relation/trust поля, provenance ids и технические JSON payloads.

## Визуальный статус

Текущая архитектура готова к последовательной замене prototype-визуала на production-ассеты без переписывания игрового слоя.

Правила выбора сцены:

1. полностью готовая и загруженная production-сцена;
2. цельная prototype-сцена;
3. partial/greybox только как последний резервный режим.

Правила отдельных player/Oren/firewood sprites:

1. production sprite;
2. prototype sprite;
3. scene greybox.

Это предотвращает визуальный откат отдельных объектов в грубые заглушки при постепенном наполнении production-набора.

## Быстрое восстановление

### Состояние ушло от демонстрационного маршрута

```powershell
powershell -ExecutionPolicy Bypass -File .\RUN_STREAM_SLICE.ps1 -Reset
```

### Порт 8000 или 5173 занят

Остановить ранее запущенный backend/Vite процесс и повторить launcher.

### Live OpenAI недоступен

Продолжить демонстрацию на локальном grounded fallback. Для гарантированно офлайн-предсказуемого показа запускать без `OPENAI_API_KEY`.

### Launcher остановлен через Ctrl+C

Web server завершается, backend останавливается в `finally`.

## Рекомендуемый формат показа

Для короткой продуктовой демонстрации достаточно 10–15 минут:

- 0–2 мин – запуск и понятная первая цель;
- 2–5 мин – Орен и основной игровой цикл;
- 5–8 мин – WAIT и автономное изменение мира;
- 8–12 мин – разговор с двумя NPC, показать различие знаний/тона/памяти;
- 12–15 мин – reload и подтверждение сохранённого состояния.

Для длинного стрима можно растянуть тот же причинный вечер до 45–60 минут через исследование, бытовые действия, разговоры и наблюдение за автономным развитием мира.
