## Причины и изменения

1. **Ожидание при запуске.** Кнопки из исходного документа были активны, пока асинхронная загрузка ещё ожидала состояние мира. Обработчики подключались позже. В исходной записи #48 нажатие завершилось примерно за 541 мс до ответа состояния; запрос действия отсутствовал. Теперь кнопки изначально отключены и включаются после подключения обработчиков.
2. **Публичный ответ разговора.** Заполненные внутренние поля памяти и типа реплики попадали в ответ `/api/dialogue`. Восстановлен существующий перечень пяти публичных полей из #45. Внутренняя память продолжает сохраняться на сервере.
3. **Повтор реплик.** Мира дважды дословно отвечала одинаково на обычное обращение. Восстановлен существующий детерминированный выбор реплик из #45, учитывающий последнюю сохранённую реплику конкретному игроку. Ответы о заданиях и причинных знаниях сохранены.
4. **Маршрут автоматического игрока.** Число `x=800` само по себе продуктового значения не имеет. Более свежие журналы #53 показали `x=297` перед отпусканием клавиши и `x=330` после отпускания, без смены канонической локации. Параллельное исправление использует зону взаимодействия и проверку остановившегося персонажа. Полный квестовый маршрут содержит собственный помощник движения и требует отдельной проверки.
5. **Проверочный кадр графики.** Документированная команда пыталась открыть векторные слои через обработчик растровых изображений. Пример исправлен на вывод `.svg`, как и уже исправленный автоматический барьер. Добавлено сохранение четырёх небольших снимков успешного либо прерванного маршрута на три дня.

Детерминированный игровой слой, канонические действия, SQLite (база данных; название читается «Эс-Кью-Лайт») и причинное происхождение знаний сохранены. Новые игровые системы и платные сервисы в этот цикл не добавлялись. Подключённый проект аналитики был пустым.

## Ручной вход после технических барьеров

Для отдельной чистой копии проекта с установленными Python (языком программирования; название «Пайтон») 3.12 и Node.js (средой выполнения; дословно «узел») 22 команда запуска из корня:

```powershell
.\RUN_STREAM_SLICE.ps1
```

Затем открыть `http://127.0.0.1:5173/?stream=1`. Программа запуска устанавливает отсутствующие зависимости. Ключ языковой модели для локального сценария не требуется. Для сохранённой игры используется та же команда без сброса.

Первые пять минут: осмотреть деревню, подойти к Мире, поговорить своими словами, закрыть разговор, исследовать берег и таверну, помочь с доступной задачей и подождать несколько шагов. Затем обновить страницу и продолжить.

Человеку требуется оценить только опыт: понятна ли доступная цель, удобны ли движение и разговор, различаются ли персонажи, заметны ли последствия поступков и хочется ли продолжать. Технические проверки сами по себе субъективную приятность игры не подтверждают.
