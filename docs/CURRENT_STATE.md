## Current implementation baseline

Текущая версия содержит ядро Shared World Kernel.

Подтвержденные системы:

- единый мир деревни;
- SQLite как источник состояния мира;
- игроки и постоянные сущности;
- детерминированные действия LOOK, MOVE, TAKE, DROP;
- события действий;
- защита повторных действий через idempotency;
- сохранение после перезапуска;
- синхронизация NPC по времени.

## Migration goal

Перевести проект к структуре:

- src – игровые системы;
- assets – визуальные ресурсы;
- tests – проверки;
- tools – автоматизация;
- docs – решения и архитектура;
- standalone – собираемый игровой пакет.

## Rules

- Не хранить архитектурные решения только в переписке.
- Сборочный HTML является результатом, а не основным местом разработки.
- Рабочие игровые механики сохраняются при миграции.
