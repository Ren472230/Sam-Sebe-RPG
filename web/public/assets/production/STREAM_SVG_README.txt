# Stream SVG Pack

Готовый временный SVG-пакет для быстрого стримового показа.

## Что внутри
- Полный набор слоёв Start Village 960x540
- Фон и передний план таверны
- Игрок, Oren, дрова, рамка диалога
- Палитра зафиксирована: молочный + графит + бирюза + алый + янтарь

## Быстрое подключение
1. Скопируй папки `village`, `tavern`, `characters`, `props`, `ui` в `web/public/assets/production/`
2. Замени `manifest.json` на файл из этого пакета
3. Запусти веб-часть проекта

## Файлы
- `manifest.json`
- `village/*.svg`
- `tavern/*.svg`
- `characters/*.svg`
- `props/firewood.svg`
- `ui/dialogue_frame.svg`
